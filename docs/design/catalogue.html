A shared visual language for three familiar tools. Based on David’s supplied references, with reusable assets and precise implementation rules.

Identity / Official whale logo

The surfacing whale is the official logo. Seven backgrounds follow the supplied startup references.

Choose a home background · The operating-system startup is already configured. The kiosk opens home directly; this is only a static logo reference.

Open the full desktop preview · Drag icons to place them. Each program opens in a window; X closes it. Learning games are placeholders until connected.

Nunito for the system. Courier Prime for the typewriter-like editor. Both bundled locally. No decorative text outside the writing itself.

14 px · metadata only, never the sole label of a child’s action.

Shape, space and touch

A

4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px spacing. Controls 14 px radius, windows 24 px, labels pill-shaped. Shadows establish only three levels: controls, windows, dialogs.

Upper-left light and soft matte surfaces. No continuous bouncing, bright glass glare or dense ornamental UI.

02 / Texten

A blank white page with typewriter text, inside a slim window with an always-visible close button.

Open the full-screen editor preview · No sidebar, title field, toolbar or permanent save counter. The document icon opens old texts directly; the title-bar X always returns to desktop. Preview text is held in memory only.

03 / Components

Consistent controls for the shell and separately hosted learning apps. Labels stay short; focus stays visible.

Utility icons & confirmation

Lucide, 24 px, 2-unit stroke. Decorative icons inherit the label color. The sound toggle demonstrates a state only; no audio is played.

Learning controls

SA

Minimum 56 px learning keys. Selected state uses outline and fill. Letter placement must also work by selecting, not only dragging.

05 / Asset family

Separate transparent masters. No labels baked into images, no sprite-sheet cropping, no runtime network dependency.

06 / One system, independent apps

The visual contract is shared. Each program keeps its own runtime, source and data.

Shell ownsEach learning app owns
Wallpaper, home, app launch, outer window and recovery statesGame layout, input, feedback, progress and embedded content
Theme choice and design-system versionThe same semantic tokens, applied inside its own page
Persistent Zuhause button and one active appNo duplicate title bar or nested desktop in embedded mode

Versioned CSS tokens are provided in src/app.css and design/tokens.json. See the specification for integration, capability negotiation and exact acceptance criteria.
